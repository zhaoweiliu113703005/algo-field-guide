廣度優先搜尋

Breadth-First Search

從起點一層一層往外擴散，找出無權圖的最短步數。

01直覺

把一顆石頭丟進池塘，水波會一圈一圈往外擴散：先碰到距離 1 的地方，再碰到距離 2 的地方。廣度優先搜尋（BFS）就是在圖上模擬這個水波。

關鍵工具是佇列（queue）：先發現的節點先處理，所以一定會把第 k 層全部處理完，才輪到第 k + 1 層。也因此，在每條邊長度都相同的圖上，第一次碰到某個節點時走的步數，就是最短步數。

用佇列一層一層往外推，第一次碰到就是最短距離。

02步驟

  1. 把起點的距離設為 0，放進佇列。
  2. 從佇列前端取出一個節點 u。
  3. 檢查 u 的每個鄰居 v：若還沒看過，令 dist[v] = dist[u] + 1 並放進佇列尾端。
  4. 重複第 2–3 步，直到佇列清空。

03手算範例

無向圖的邊為 A–B、A–C、B–D、C–D、C–E、D–F、E–F，從 A 出發。

取出新發現（距離）佇列內容說明
—A(0)A起點入佇列
AB(1), C(1)B C第 1 層
BD(2)C DA 已看過，略過
CE(2)D EA、D 已看過，只新增 E
DF(3)E F第 3 層
E—FC、F 都已看過
F—（空）佇列清空，結束

結果：A=0、B=1、C=1、D=2、E=2、F=3。注意 F 雖然也能從 E 到達，但在 D 那一步就已經以距離 3 被發現了。

04複雜度

時間（鄰接串列）
O(V + E)

每個節點進出佇列一次，每條邊最多被檢查兩次。

時間（鄰接矩陣）
O(V²)

找鄰居要掃整列，每個節點都要花 O(V)。

空間
O(V)

距離表與佇列最多各存 V 個節點。

05Python 實作

from collections import deque


def bfs(graph: dict[str, list[str]], start: str) -> dict[str, int]:
    """回傳每個可到達節點與 start 之間的最短步數。"""
    dist = {start: 0}
    queue = deque([start])
    while queue:
        u = queue.popleft()             # 先進先出：一層一層處理
        for v in graph[u]:
            if v not in dist:           # 第一次看到就是最短距離
                dist[v] = dist[u] + 1
                queue.append(v)
    return dist


if __name__ == "__main__":
    g = {
        "A": ["B", "C"], "B": ["A", "D"], "C": ["A", "D", "E"],
        "D": ["B", "C", "F"], "E": ["C", "F"], "F": ["D", "E"],
    }
    print(bfs(g, "A"))
    # {'A': 0, 'B': 1, 'C': 1, 'D': 2, 'E': 2, 'F': 3}

06常見陷阱

出佇列時才標記已拜訪　同一個節點可能被好幾個鄰居重複放進佇列，浪費時間甚至算錯距離。要在放進佇列的當下就記錄距離。

用 list.pop(0) 當佇列　每次 pop(0) 都要搬移整個 list，是 O(n)。請用 collections.deque 的 popleft()。

拿來算加權圖的最短路徑　BFS 只數「幾步」，不看邊的權重。邊有不同長度時要改用 Dijkstra。

07相關演算法

  • Dijkstra 最短路徑　把 BFS 的佇列換成優先佇列，就能處理邊有權重的圖。

快速排序

Quicksort

選一個基準值，把陣列分成小的一邊與大的一邊，再遞迴排序。

01直覺

體育課要全班依身高排隊。老師隨便點一位同學當「基準」，喊：比他矮的站左邊、比他高的站右邊。這一喊之後，基準同學的位置就永遠確定了，左右兩群再各自用同樣的方法排。

快速排序就是這個「分割（partition）→ 遞迴」的過程。每次分割都會讓一個元素歸位，而且左右兩群之間不必再互相比較。

挑一個基準值讓它歸位，左右兩邊各自再做一次。

02步驟

  1. 若目前區間只有 0 或 1 個元素，直接結束。
  2. 選區間最後一個元素當基準值（pivot）。
  3. 由左往右掃描，把比基準值小的元素依序換到區間前段。
  4. 把基準值換到「小的那一段」的後面，它就到了最終位置。
  5. 對基準值左邊與右邊的區間分別遞迴，重複以上步驟。

03手算範例

對 [5, 2, 9, 1, 6, 3] 做第一次分割，基準值是最後一個元素 3。i 指向下一個「小元素」該放的位置。

04複雜度

最佳時間
O(n log n)

每次都剛好對半分，遞迴深度 log n，每層總共掃 n 個。

平均時間
O(n log n)

隨機資料下，分割大致平衡，期望比較次數約 1.39 n log₂ n。

最差時間
O(n²)

每次基準值都是最大或最小值（例如輸入已排序），深度變成 n。

空間
O(log n)

原地排序，只有遞迴堆疊；最差情況會到 O(n)。

05Python 實作

def partition(a: list[int], lo: int, hi: int) -> int:
    """Lomuto 分割：以 a[hi] 為基準值，回傳基準值最後的位置。"""
    pivot = a[hi]
    i = lo                              # a[lo:i] 都比 pivot 小
    for j in range(lo, hi):
        if a[j] < pivot:
            a[i], a[j] = a[j], a[i]
            i += 1
    a[i], a[hi] = a[hi], a[i]           # 基準值歸位
    return i


def quicksort(a: list[int]) -> None:
    """原地排序 a。"""
    def sort(lo: int, hi: int) -> None:
        if lo >= hi:                    # 0 或 1 個元素：已排好
            return
        p = partition(a, lo, hi)
        sort(lo, p - 1)
        sort(p + 1, hi)

    sort(0, len(a) - 1)


if __name__ == "__main__":
    data = [5, 2, 9, 1, 6, 3]
    quicksort(data)
    print(data)  # [1, 2, 3, 5, 6, 9]

06常見陷阱

已排序的輸入反而最慢　固定選最後一個當基準值，遇到已排序資料就退化成 O(n²)。實務上先隨機挑一個位置與 a[hi] 交換再分割。

遞迴太深　Python 預設遞迴上限約 1000 層，最差情況會觸發 RecursionError。可以先遞迴較短的一邊、較長的一邊改用迴圈。

以為它是穩定排序　交換會打亂相同值元素的原始順序。需要穩定性時（例如先依姓名、再依分數排序）請改用合併排序或 Python 內建的 sorted()。

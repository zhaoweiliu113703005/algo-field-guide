Binary Search

01直覺

想像翻一本按注音排好的字典找「ㄓ」開頭的字：你不會從第一頁翻起，而是直接翻到中間，看看現在在「ㄓ」的前面還是後面，再決定往哪一半繼續翻。每看一次，剩下要翻的頁數就少一半。

二分搜尋就是把這個動作寫成程式。它唯一的前提是：資料必須已經排序，這樣看中間那一格才能判斷答案在左邊還是右邊。

看中間，丟掉不可能的一半，重複到找到或範圍變空。

02步驟

  1. 設定搜尋範圍為整個陣列：lo = 0、hi = n - 1（閉區間）。
  2. 當 lo <= hi 時，取中間位置 mid = (lo + hi) // 2。
  3. 比較 arr[mid] 與目標：相等就回傳 mid。
  4. 若 arr[mid] 比目標小，答案只可能在右半邊，令 lo = mid + 1。
  5. 若 arr[mid] 比目標大，答案只可能在左半邊，令 hi = mid - 1。
  6. 迴圈結束仍沒找到，回傳 -1。

03手算範例

在 [3, 8, 15, 21, 34, 42, 57, 66]（索引 0–7）中找 57。

回合lohimidarr[mid]說明
10732121 < 57，丟掉左半，lo 改為 4
24754242 < 57，再丟掉左半，lo 改為 6
367657相等，回傳索引 6

8 個元素只比較了 3 次就找到，剛好是 log₂ 8 = 3。

04複雜度

最佳時間
O(1)

第一次看的中間值就是目標。

平均時間
O(log n)

每回合範圍減半，約 log₂ n 回合後只剩 1 個。

最差時間
O(log n)

目標不存在時，要一路減半到範圍為空。

空間
O(1)

迴圈版只用 lo、hi、mid 三個變數。

05Python 實作

def binary_search(arr: list[int], target: int) -> int:
    """在已排序的 arr 中找 target，回傳索引；找不到回傳 -1。"""
    lo, hi = 0, len(arr) - 1        # 閉區間 [lo, hi]
    while lo <= hi:                 # 區間不為空就繼續
        mid = (lo + hi) // 2
        if arr[mid] == target:
            return mid
        if arr[mid] < target:
            lo = mid + 1            # 答案在右半邊
        else:
            hi = mid - 1            # 答案在左半邊
    return -1


if __name__ == "__main__":
    data = [3, 8, 15, 21, 34, 42, 57, 66]
    print(binary_search(data, 57))  # 6
    print(binary_search(data, 10))  # -1

06常見陷阱

區間定義前後不一致　用閉區間 [lo, hi] 就要配 while lo <= hi 與 hi = mid - 1；用半開區間 [lo, hi) 則配 while lo < hi 與 hi = mid。混用會漏掉元素或無窮迴圈。

忘了先排序　對未排序的資料做二分搜尋不會報錯，只會安靜地回傳錯誤答案。

中點溢位　Python 整數不會溢位，但在 C／Java 中 (lo + hi) / 2 可能溢位，要寫成 lo + (hi - lo) / 2。
